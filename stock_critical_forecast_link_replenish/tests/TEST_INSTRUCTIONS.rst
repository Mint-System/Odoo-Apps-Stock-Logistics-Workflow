- Open the Inventory app
- Under Operations menu click "Calculate Critical Forecast"
- Under Reporting menu open the Critical Forecast
- Critical forecast is shown for products in inventory, manufacturing and reordering
- Create the replenishment rule for a product, set the minimum and maximum quantities
- Set the route to "Buy", assign a vendor
- If the forecasted quantity for a product is less than the minimum quantity, the reorder button will appear and a purchased order can be generated by clicking it
- The truck icon is now also visible in the Critical Forecast and the replenishment screen can be accessed from there
