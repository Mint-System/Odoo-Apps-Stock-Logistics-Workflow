Setup:

- Choose product with serial number or lot tracking.
- Set *Serial Number Prefix*

Check default serial number / lot:

- Generate purchase order for product with serial or lot tracking and confirm.
- Control Receipt by clicking Smart Button.
- Open stock move of order by clicking on corresponding inline button.
- Click *Generate Serials/Lot* and check *First Serial Number* / *First Lot Number*.
- If product has no serials / lots up to now a new serial / lot is generated from prefix and random number.
- If product has already serials / lots the suggested first serial number is last serial / lot risen by 1 in numeric part.
