Purchase order:

- Open Purchase > Orders > Purchase Orders
- Create a new Purchase Order for Azure Interior
- Add product line (e.g. Bolt, Screw, Drawer), the line position numbers will be added
- Confirm the order and open the Delivery form, the line position numbers are preserved from the Purchase Order

Sales Order:

- Open Sales > Orders > Quotations
- Create a new Quotation for Azure Interior
- Add product line (e.g. Bolt, Screw, Drawer), the line position numbers can be set by activating Actions > Set position numbers
- Confirm the order and open the Delivery form, the line position numbers are preserved from the Sales Order
